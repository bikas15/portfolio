How to play

Flip every tile blue. The symbol on each tile tells you what a press flips. In Campaign, the clock starts with the first move on timed levels.

Use Arrow keys to move and Enter or Space to press. Select Trace to preview a move before applying it on a touchscreen. Par is the fewest possible moves.

Daily Signal has no timer. In Circuit Lab, set tile patterns, tap a few tiles to scramble the grid, then test it or copy the puzzle code.
